**TWIN** — это мобильное приложение для осознанного знакомства, которое помогает найти действительно подходящего партнера. В отличие от стандартных свайпов, TWIN использует глубокий психологический анализ и многофакторный алгоритм для поиска людей, совместимых с вами по характеру, ценностям и жизненным целям.

## Идея проекта

Мы считаем, что крепкие отношения строятся на фундаменте общих ценностей и взаимопонимания. TWIN предлагает пользователям уйти от поверхностного выбора и сосредоточиться на реальной совместимости. Наше приложение — это ваш личный помощник в поиске "того самого" человека, с которым вы сможете построить гармоничные и долгосрочные отношения.

## Технологический стек

В разработке приложения мы используем современные и надежные технологии:

*   **Фронтенд:** [Flutter](https://flutter.dev/) — для создания красивых и производительных интерфейсов на iOS и Android из единой кодовой базы.
*   **Бэкенд:** [Dart](https://dart.dev/) (на базе фреймворка [Shelf](https://pub.dev/packages/shelf) или [Aqueduct](https://aqueduct.io/)/[Serverpod](https://www.serverpod.dev/)) — для написания логики серверной части на том же языке, что и клиент.
*   **Дизайн:** [Figma](https://www.figma.com/) — для проектирования пользовательского опыта (UX) и интерфейсов (UI).
*   **База данных:** [PostgreSQL](https://www.postgresql.org/) — надежная и масштабируемая реляционная база данных для хранения профилей, результатов тестов и метрик совместимости.
*   **Командная работа и CI/CD:** [GitHub](https://github.com/) — для управления версиями кода, постановки задач и организации совместной работы.

## Основные функции (планируемые)

*   **Глубокое анкетирование:** Интерактивный психологический тест для определения типа личности, ценностей и предпочтений пользователя.
*   **Многофакторный алгоритм:** Умный поиск, который анализирует десятки параметров для расчета процента совместимости между людьми.
*   **Профили совместимости:** Наглядное отображение сильных сторон потенциальной пары и областей для роста.
*   **Осознанные знакомства:** Отсутствие бесконечных свайпов. Фокус на качественных совпадениях с высоким процентом совместимости.
